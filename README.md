IMS DevSecOps Capstone
Customer
Acme Retail Ltd.

Role
Cloud & DevSecOps Engineer

Project Overview
Acme Retail Ltd. is modernizing its engineering organization through an AI-Driven Cloud & DevSecOps Modernization Program. The Inventory Management System (IMS) is ready for deployment, but the existing engineering processes are manual, inconsistent, and difficult to scale.

This project demonstrates the implementation of Infrastructure as Code, CI/CD automation, security validation, testing, documentation, and AI Engineering Specifications.

Manual Deployments

Solution Overview
The solution includes:

Infrastructure as Code using Terraform
CI/CD automation using GitHub Actions
Docker containerization
Security validation controls
Testing strategy and validation
AI Engineering Specifications
